# Технічне завдання: CakeHub

## 1. Назва та короткий опис проєкту
CakeHub — вебзастосунок для продажу кондитерських виробів. Онлайн-платформа для перегляду, вибору та замовлення тортів, тістечок, макаронс, капкейків з фільтрацією за дієтичними потребами.

## 2. Проблема, яку вирішує вебзастосунок
Покупцям складно знайти якісні десерти з урахуванням дієтичних обмежень. Кондитерам бракує централізованої платформи для приймання замовлень.

## 3. Мета проєкту та цільова аудиторія
Мета: створити зручну платформу для вітрини десертів із прозорою системою замовлень.
Аудиторія: покупці (святкові замовлення, дієтичні потреби) та кондитери/власники пекарень.

## 4. Ролі
- Гість — переглядає каталог, додає в кошик
- Користувач — оформлює замовлення, залишає відгуки
- Модератор — перевіряє відгуки та скарги
- Адміністратор — керує каталогом, замовленнями, ролями

## 5. Основні функції
Каталог з фільтрами, кошик, оформлення замовлення, система відгуків, адмін-панель, модерація.

## 6. Функціональні й нефункціональні вимоги
Функціональні: пошук, фільтрація, CRUD для товарів, історія замовлень.
Нефункціональні: адаптивність, швидкодія (до 2 сек), безпека (хешування паролів, захист від XSS).

## 7. Обмеження проєкту
Логістичні: доставка обмежена регіоном. Технічні: тільки веб-версія. Юридичні: дисклеймери щодо алергенів.

## 8. Критерії готовності першої версії
Користувач може зареєструватися, обрати десерти та оформити замовлення. Адміністратор може додати товар і змінити статус замовлення. Модератор може приховувати спам-відгуки.

## 9. Перелік сторінок
- Головна (ознайомлення з акціями)
- Каталог (вибір виробів з фільтрами)
- Сторінка товару (детальна інформація, склад, відгуки)
- Кошик та Оформлення (підсумок вибору, введення даних)
- Вхід і реєстрація (створення акаунта)
- Особистий кабінет (управління профілем, історія замовлень)
- Панель модератора (перевірка відгуків, скарги)
- Панель адміністратора (управління каталогом, замовленнями, ролями)
