# Сценарії використання: CakeHub

## Сценарій 1: Гість — Пошук десерту за дієтичними потребами
**Мета:** Знайти десерт без цукру
**Початкові умови:** Гість відкрив головну сторінку
**Дії:** Переходить у каталог → відкриває фільтри → обирає «Без цукру» → натискає «Застосувати»
**Реакція системи:** Фільтрує базу даних, оновлює сітку товарів
**Результат:** Відображаються лише десерти без цукру
**Помилка:** Якщо немає товарів — показує «Нічого не знайдено»

## Сценарій 2: Користувач — Оформлення замовлення
**Мета:** Оформити замовлення на доставку торта
**Початкові умови:** Користувач авторизований, торт у кошику
**Дії:** Відкриває кошик → вводить адресу → обирає дату/час → натискає «Оформити»
**Реакція системи:** Перевіряє доступність часу, створює замовлення, надсилає email
**Результат:** Замовлення створено, показує номер та статус
**Помилка:** Якщо час зайнятий — пропонує обрати інший слот

## Сценарій 3: Модератор — Опрацювання скарги на відгук
**Мета:** Приховати нецензурний відгук
**Початкові умови:** Модератор авторизований, є активна скарга
**Дії:** Відкриває панель модератора → переходить до «Скарги» → читає відгук → натискає «Приховати» → «Закрити скаргу»
**Реакція системи:** Змінює видимість відгуку, оновлює статус скарги
**Результат:** Скаргу опрацьовано, порушення усунуто
**Альтернатива:** Якщо відгук не порушує правил — «Залишити відгук»

## Сценарій 4: Адміністратор — Додавання нового торта
**Мета:** Додати новий торт до каталогу
**Початкові умови:** Адміністратор авторизований, підготовлено опис, ціну, фото
**Дії:** Відкриває адмін-панель → «Додати товар» → заповнює назву, категорію, ціну, склад → завантажує фото → «Зберегти»
**Реакція системи:** Валідує дані, зберігає запис, оновлює каталог
**Результат:** Торт додано і доступний для купівлі
**Помилка:** Якщо не заповнено обов'язкове поле — підсвічує помилку
