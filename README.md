# CakeHub

Вебзастосунок для продажу кондитерських виробів.

## 1. Назва та короткий опис проєкту
CakeHub — це онлайн-платформа (інтернет-магазин) для перегляду, вибору та замовлення кондитерських виробів: тортів, тістечок, макаронс, капкейків. Платформа підтримує фільтрацію за дієтичними потребами (без цукру, веган, без глютену) та оформлення замовлень на доставку або самовивіз.

## 2. Проблема, мета й цільова аудиторія
**Проблема:** покупцям складно знайти якісні десерти з урахуванням дієтичних обмежень, а кондитерам — централізовано приймати замовлення.
**Мета:** створити зручну платформу для вітрини десертів із прозорою системою замовлень і відгуків.
**Цільова аудиторія:** покупці (святкові замовлення, дієтичні потреби) та кондитери/власники пекарень.

## 3. Ролі користувачів
- **Гість** — переглядає каталог, додає в кошик.
- **Користувач** — оформлює замовлення, залишає відгуки, керує профілем.
- **Модератор** — перевіряє відгуки та скарги.
- **Адміністратор** — керує каталогом, замовленнями, ролями.

## 4. Основні функції та сторінки
**Функції:** каталог з фільтрами, кошик, оформлення замовлення, система відгуків, адмін-панель, модерація.
**Сторінки:** Головна, Каталог, Сторінка товару, Кошик, Вхід/Реєстрація, Особистий кабінет, Панель модератора, Панель адміністратора.

## 5. Склад команди й відповідальність
- **Окунєв Олександр** — Backend-розробник (база даних, API).
- **UI/UX Дизайнер** — макети інтерфейсу.
- **Frontend-розробник** — верстка та клієнтська логіка.
- **QA-інженер** — тестування.
- **Менеджер проєкту** — координація, ТЗ.
